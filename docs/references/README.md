# References

Manual notes, schematic notes and reference recordings used for calibration (Stage 6).

- Put your own notes as Markdown files here.
- Audio files (`*.wav`, `*.aif`, `*.flac`, `*.mp3`) in this folder are ignored by Git
  (see `.gitignore`) because they are large and may not be freely licensed.
  Record the source and licence of each file in `sources.md` instead.
- Only freely licensed or self-made audio may be committed or shipped (CLAUDE.md, Section 9).
